## 三、架构设计演进历程

### 阶段一：基础脚手架搭建

基于 Vite + Vue 3 + TypeScript 模板初始化，配置路径别名 `@/`、Vite 代理转发到后端 API、搭建 Pinia + Vue Router 基础架构。

### 阶段二：左右分栏界面（已迭代重构）

最初设计为**"左侧聊天框 + 右侧参数面板"**布局，用户通过表单对话与 AI 协作生成视频方案。

### 阶段三：无限画布节点流重构（核心架构革新）

将传统表单对话重构为**视觉化节点工作流**，是项目最关键的架构升级：

1. **无限画布** — 支持无限平移（pan）与缩放（zoom）的点阵网格画布，替代固定布局。创作要素封装为卡片节点（FlowNode：text / image / video），通过 SVG 贝塞尔曲线连线表达上下文流动关系。

2. **多节点框选与协同拖拽** — 实现鼠标拖拽矩形选框多选（碰撞检测），选中节点可集体拖拽平移。

3. **Agent 抽屉** — 右侧可滑入/滑出的 Agent 飞出面板替代固定对话区。支持拖入节点作为 AI 参考（referencedNodes），画布空白处双击才收起，避免误关闭。

4. **画布数据模型** — 定义完整的 `CanvasDocument`，配套 `canvasState.ts` 实现**三路合并算法**（`mergeCanvas(base, local, remote)`），解决本地编辑与服务器返回的冲突。

5. **画布持久化层** — `CanvasPersistence` 类提供 localStorage 本地兜底 + 云端同步，含去抖保存（700ms）、版本号乐观锁、冲突检测与用户选择解决。

### 阶段四：视频剪辑编辑器（/editor）

独立剪辑工程编辑路线，技术特点：

- **三栏布局**：左侧素材面板 → 中间实时预览 → 右侧属性检查器
- **多轨道时间轴**：文本轨、视频轨、音频轨分层管理
- **Canvas 实时渲染**：`useClipEngine` 实现帧级渲染、视频播放、逐帧步进
- **导出功能**：`canvas.captureStream()` + `MediaRecorder` 纯前端导出 WebM/MP4
- **本地文件系统工作区**：利用 **File System Access API** + **IndexedDB** 实现三级素材加载（本地缓存 → 本地目录 → 云端下载自动持久化）
- **撤销/重做**：50 层历史栈

### 阶段五：TV 频道模块（/tv）

全屏沉浸式视频轮播功能：

- 全屏视频播放器，支持左右箭头和触屏滑动切换
- 提示词折叠展开 + 一键复制
- 管理员后台（/tv/admin）：视频素材 CRUD、发布/下架

### 阶段六：访问统计

匿名访问统计系统，技术要点：

- `SiteTrafficTracker` 应用启动时安装
- `navigator.locks` 跨标签页串行化请求
- 后端 HttpOnly Cookie 去重，30 分钟滑动窗口
- 统计接口未就绪时页面正常降级显示

### 阶段七：API 配置中心（/settings/api）

支持用户自由配置自有视频生成 API：

- 个人账户信息展示与登出
- **BYOK**（自备视频 API）：配置多模型（Veo 2、Seedance 2.5 等）接口密钥
- 配置管理：编辑名称、更新密钥、验证连接、删除

### 阶段八：模型适配与素材适配（2026-10-15 两轮迭代）

- 从 `GET /video-generation-target` 动态读取平台模型能力，取消前端硬编码
- 审理请求携带通道、模式、素材角色，分离"原始设置"与"最终参数"
- `generationState.ts` 严格匹配：来源、参数、目标指纹变更后需重新审理
- 支持 Seedance 2.5 时长范围（4–15 秒整数）、分辨率限制、图片约束
- 图片审理由后端完成，前端展示说明，不增加额外适配预览
## 四、核心服务层设计

### 4.1 Axios 请求封装（request.ts）

- **CSRF 防护**：POST / PUT / PATCH / DELETE 自动从 `hw_csrf` Cookie 读取令牌注入请求头
- **401 拦截**：自动跳转登录页并携带 `redirect` 参数
- **错误规范化**：提取后端 `{ code, message, request_id }` 错误结构

### 4.2 画布三路合并算法（canvasState.ts）

```typescript
mergeCanvas(base, local, remote) => { document: CanvasDocument; conflicts: string[] }
```

- 节点级冲突处理：`content` 冲突自动转为 `pending_ai` 暂存 AI 建议
- 标量属性递归合并：同属性双方均修改则记录冲突路径
- 列表 ID 级合并：本地删除 > 远程 AI 新增

### 4.3 视频生成状态机（generationState.ts）

| 函数 | 功能 |
|---|---|
| `generationSources()` | 从画布提取生成源节点列表 |
| `generationContextMatches()` | 检查生成上下文是否仍然一致 |
| `generationMatches()` | 完整检查：上下文 + 审核状态 + 指纹 |
| `savedVideoReview()` | 获取已保存的审核结果 |
| `videoGenerationBlockReason()` | 返回 15+ 种阻塞原因的详情字符串 |
| `videoSettingsBlockReason()` | 检查时长/分辨率配置是否合法 |
| `videoDurationChoices()` | 获取当前模型允许的时长列表 |

### 4.4 画布持久化层（canvasPersistence.ts）

- **去抖保存**：700ms 防抖，编辑时同步写入 localStorage 兜底
- **版本乐观锁**：PUT 时携带 `expected_canvas_version`，409 冲突时自动重新加载合并
- **重试机制**：最多 6 次自动重试，网络恢复后自动同步
- **冲突解决**：用户可选择保留本地或远程版本，冲突备份到 `*:conflict-backup` key

### 4.5 资料库 API（libraryApi.ts）

- 存储配额查询、素材分页检索、工程草稿 CRUD
- 华为云 OBS 预签名直传流程：`requestUploadIntent` → OBS 直传 → `completeUpload`

### 4.6 本地文件系统工作区（useFileSystemWorkspace.ts）

三级素材加载决策链：

```
Level 1: 内存缓存 → Level 2: 本地目录已有文件 → Level 3: 云端下载并自动写回本地
```

- 使用 File System Access API 挂载用户本地目录
- IndexedDB 持久化文件句柄，跨页面复用

## 七、UI/UX 设计风格

- **暗色主题**：`#0c0f17` 基调色，`#6366f1`（靛蓝）主色调，`#38bdf8`（天蓝）高光色
- **沉浸式体验**：首页星光粒子 + 流动斜线动态背景，整屏吸附滚动
- **响应式适配**：各页面均含 `@media (max-width: 768px)` 移动端适配
- **深色 UI 控制台风格**：透明毛玻璃卡片、渐变按钮、胶囊标签、SVG 图标
- **字体系统**：系统原生字体栈（SF / Segoe UI / PingFang SC / Microsoft YaHei）
