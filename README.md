# hello-world
项目名称：“Hello World”一个国际传播方向特化的AI视频生成平台

团队名称：你好世界
参赛组别：文学、历史学、哲学组（语言智能、国际传播）
实践形式：软硬件开发
简介：近年来，中国国家整体实力稳步上升，日益走近世界舞台中央；然而在当下“西强我弱”的国际舆论格局中，我们在对外传播上仍存在显著的“信息流进流出的‘逆差’、国家真实形象和西方主观印象的‘反差’、软实力和硬实力的‘落差’”，国际受众对中国的认知依旧存在滞后甚至误解。在此背景下，如何创新传播手段、构建融通中外的话语表达并促进“民心相通”，成为新时代国际传播亟待破解的现实课题。 
在移动互联时代，视频凭借叙事生动、视听沉浸与强感染力，已成为打破西方话语壁垒、进行国际传播的绝佳载体。然而，当前开展优质短视频创作面临显著瓶颈：无论是实景拍摄还是CG制作，均耗费大量的时间与金钱成本，极大地限制了民间多元主体参与国际传播的活力。为了解决这一问题，团队在开展国际传播方向的社会实践时发现，伴随AIGC技术的演进，AI生成视频已经成为一种高质高效的新兴路径，人工智能深度赋能国际传播已不再是一句“空话”，而是切实可行的时代机遇。 
然而，在深入调研与测试现有主流AI视频生成平台后，团队发现其在服务国际传播场景时仍存在两大明显痛点：
第一，现有平台通常采用直接绑定单一内置模型的封闭形式，不仅限制了用户调用的灵活性，且使用成本居高不下； 
第二，当前严重缺乏专门聚焦于国际传播方向的特化平台，缺少针对跨文化传播、分众精准传播与叙事话语构建的专业指引，导致相关方向的用户只能停留在基础的通用模型操作层面，在提升传播实效与受众共情上面临明显的上升瓶颈。 
针对上述痛点，团队聚焦“人工智能赋能国际传播”，力图打造一款能够覆盖国际传播方向视频生成全流程的特化AI视频生成平台，从最初的传播目标与受众选择，到生产全过程中的跨文化叙事指导，全方位精准满足国际传播方向用户的创作需求。 
在此基础上团队还衍生出了一种新的AI视频生成平台样式，即在保留了平台提供相关AI的基础上，为用户提供可自由配置API的空间。现在的AI视频模型存在的一个问题在于，擅长方向不同，部分模型以画面精美为优势，部分模型则以衔接（可以确定首尾帧）为优势，这使得要生成一个完整的视频通常需要使用多个视频模型（然而不同的模型可能来自于不同的公司，导致用户不得不奔波于不同平台）。团队的这种新的平台样式，使得用户使用时可以更好的完成完整视频的生成，不至于在不同平台间进行奔波。这种自由配置API的空间样式相比于传统样式的另一个优势在于，可以更好的跟上AI视频生成模型的迭代速度，因为不同于普通的固定死的平台，用户可以自行配置当前满足其要求的模型（生成质量最高、价格最便宜等）。
为了满足平台的平稳运行，团队设计了未来的两种付费模式，第一是会员制，当用户付费购置会员时（团队不准备以此为主要盈利方向，因此这方向的付费只是象征性的），可以解锁自由配置API的功能。第二是直接买卖Token，当用户使用平台直接提供的模型时，需要付费购买Token。
本项目预计以华罗庚先生的统筹优选法为基础进行团队管理，力求更好的发挥每个人的力量以节约人力物力。
当前项目处于Demo阶段，预计先实现简单的视频生成功能（包括自由配置的视频生成模型API以及agent API）以及简单的国际传播方向特化（使用AI进行简单的国际传播方向指导）。之后，在提升阶段，团队将聚焦于实现上文所提及的新的平台样式，同时完善国际传播方向特化（暂时有两个方案，1.由具备专业能力的专业人才编写数据库，将此数据库交给AI，进行指导。2.通过合法合规手段获取各个国外平台的各国的热点方向、热点视频，用于视频生成指导）。未来，在上面两个阶段的基础上，团队预备继续打磨平台，完备收费功能，维持平台运转，实现盈利。
